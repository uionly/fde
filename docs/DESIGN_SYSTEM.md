# Design System Direction

## Brand Character

Professional engineering lab.

Keywords:
- technical
- clear
- modern
- precise
- credible
- interactive

## Color

Use a neutral system with orange as the primary accent.

Do not overuse orange backgrounds.

Use orange for:
- primary CTA
- active navigation
- progress accent
- experiment highlights
- selected states where accessible

## Typography

Prefer a modern sans-serif for UI and readable prose.

Monospace for:
- code
- JSON
- logs
- terminal/evidence panels

## Layout

Lesson prose max width around 720–780px.

Desktop shell:
- top header
- optional left track navigation
- main content
- right lesson TOC where appropriate

## Components to establish early

- AppShell
- MainNav
- PageHeader
- TrackCard
- LessonListItem
- ProgressBar
- DifficultyBadge
- FDEPrinciple
- CustomerScenario
- Callout
- EvidencePanel
- ExperimentShell
- QuestionCard
- ResultExplanation
- LabStep
- EmptyState
- ErrorState
- Skeletons

## Interaction

Keep animation subtle and functional.

Avoid:
- bouncing rewards
- confetti
- cartoon achievements
- game currency

Use:
- progress completion
- checkmarks
- skill improvements
- understated streaks
