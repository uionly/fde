# Design System Direction

## Brand Character

Professional engineering lab.

Keywords:
- technical
- clear
- modern
- precise
- credible
- interactive

## Color

Use the TO THE NEW brand system: an ink/gray neutral foundation, magenta primary, and cyan accent.

Do not overuse saturated backgrounds.

Use magenta for:
- primary CTA
- active navigation
- progress accent
- selected states where accessible

Use cyan for:
- experiment and AI-coach highlights
- supporting information
- selected-state surfaces paired with accessible dark cyan text

Status colors use the branded emerald (success), rose (error), and amber (warning) ramps.

## Typography

Use Montserrat for UI, headings, and readable prose. Hierarchy comes from weight, scale, and spacing rather than a serif/sans split.

Monospace for:
- code
- JSON
- logs
- terminal/evidence panels

## Layout

Lesson prose max width around 720–780px.

Desktop shell:
- top header
- optional left track navigation
- main content
- right lesson TOC where appropriate

## Interaction

Keep animation subtle and functional.

Avoid:
- bouncing rewards
- confetti
- cartoon achievements
- game currency

Use:
- progress completion
- checkmarks
- skill improvements
- understated streaks
