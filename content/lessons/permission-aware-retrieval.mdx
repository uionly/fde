## Retrieval is an authorization boundary

An answer is not safe merely because the user is authenticated. The retrieval layer must enforce the source permissions that apply to that specific identity.

<CustomerScenario title="A demo that leaks">
  A support specialist asks about refund exceptions. Naive vector search retrieves a manager-only policy because the chunks were indexed without access metadata.
</CustomerScenario>

<MermaidDiagram chart={`flowchart LR
  U[User + identity] --> A[Application]
  A --> R[Permission-aware retrieval]
  R --> P[(Policy index)]
  R --> M[Model]`} />

<FDEPrinciple variant="warning">
  Authorization must travel with the query; prompt instructions are not an access-control system.
</FDEPrinciple>
